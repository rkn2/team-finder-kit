    How this works

    1. Load your roster (the same CSV you uploaded to ChatGPT or Claude). The made-up sample roster loads until you do.
    2. In ChatGPT or Claude, paste a funding call. When it has built the teams, ask "Give me the dashboard JSON."
    3. Paste that block under Add results.
    4. Pick an option (A, B, C), mark each person ✓ In, ? Maybe or ✗ Out, add notes, and add anyone else from the roster.
    5. Copy the email. People marked Out drop off the To line. The email text was written for the original team, so edit it if you changed the team.

    Everything stays in this browser on this computer. Nothing is sent anywhere. To move your work to another computer or share it, use Save everything to a file, then Open a saved file on the other end.
